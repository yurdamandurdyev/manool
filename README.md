# MANOOL — рабочая основа сайта

Стек: Astro, React, TypeScript, SCSS, Tailwind CSS, Three.js.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` проверяет типы и собирает пять статических страниц в `dist/`.

## Структура

- `src/pages/`: главная, cases, contacts, articles, about.
- `src/components/ui/pearl-button.tsx`: PearlButton и вариант ссылки PearlLink.
- `src/components/ui/demo.tsx`: пример кнопки.
- `src/components/ModelViewer.tsx`: загрузка FBX и плавный поворот по позиции курсора.
- `src/styles/site.scss`: оформление, адаптивные размеры и оранжевая версия Pearl.
- `src/styles/global.css`: Tailwind.
- `public/assets/`: переданные оригиналы модели, логотипа и знака.

Проект уже настроен для shadcn: `components.json`, TypeScript, Tailwind и `cn` готовы. Путь `@/components/ui` соответствует `src/components/ui` — это папка `/components/ui` внутри исходников Astro. Она нужна для единообразного импорта и размещения UI-компонентов; дублировать её в корне не нужно. Pearl не требует провайдеров или дополнительных зависимостей помимо React. Стили вынесены из JSX в общий SCSS. Для навигации используются настоящие ссылки с тем же оформлением.

## Не хватает текстур FBX

Исходный FBX ссылается на внешние изображения, которые не были переданы:

- `ChatGPT Image 26 сент. 2026 г., 04_26_02.png`
- `ChatGPT Image 26 сент. 2026 г., 04_51_19.png`

Рисунок воссоздан по предоставленному референсу: жёлтые глаза, тёмные зрачки и четыре пятна. `src/components/manool-material.ts` рисует CanvasTexture и проецирует её на передние грани исходной геометрии FBX; задние грани остаются оранжевыми. Это приближение, а не восстановленные оригинальные текстуры. После получения исходных PNG можно вернуть материалы FBX, убрать placeholder-загрузчик и настроить resourcePath.

Наполнение кейсов, контактов, статей и страницы о студии ожидает материалов владельца. Фирменные JPEG сохранены без изменений, включая жёлтый в оригиналах. Остальной интерфейс чёрно-оранжевый. На сенсорных устройствах модель статична; при prefers-reduced-motion движение отключено.

## Навигация и прелоудер

`src/components/unlumen-ui/dock.tsx` — локальная реализация Dock без сторонней анимационной библиотеки. Поддерживает items, magnification, distance, springOptions; на сайте увеличение 1.22, радиус 120 px, stiffness 400, damping 25. Измеряются неподвижные контейнеры кнопок, чтобы масштабирование не вызывало дрожания. На телефоне и при reduced motion увеличение отключено, ссылки работают без JavaScript.

`src/components/Preloader.astro` показывает оригинальный логотип на главной: три полосы собираются в изображение, затем заставка исчезает по событию готовности модели. Минимальная длительность 1.6 секунды; пропуск, ошибки WebGL/FBX и таймаут 6.5 секунды не блокируют доступ к сайту. Без JavaScript и при reduced motion заставка скрыта.

## Главный экран и LayeredText

Главный экран состоит из текстового блока слева и уменьшенной модели справа; до 800 px блоки идут друг под другом. `src/components/ui/layered-text.tsx` адаптирует предоставленный эффект складчатого текста под фирменные оранжевые цвета. GSAP анимирует строки при наведении и фокусе, на сенсорном экране — при касании. При reduced motion текст статичен. Высота перемещения соответствует параметрам lineHeight / lineHeightMd; при смене ширины GSAP пересоздаёт анимацию. Пример использования — `src/components/ui/layered-text-demo.tsx`.
